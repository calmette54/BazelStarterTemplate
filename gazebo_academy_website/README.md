# GazeboMaster Academy Website

🎓 **A Beautiful Educational Platform for Monetizing Gazebo Harmonic Tutorials**

A comprehensive, beautifully designed website created to monetize the extensive Gazebo Harmonic LTS tutorial we developed. Features a freemium model with progressive learning modules.

## 🎯 Project Overview

This website serves as the monetization platform for the comprehensive `tutorial_gazebo` project, transforming 37+ code examples and 8 progressive modules into a premium educational experience.

### Key Features

- **🎨 Beautiful Design**: Modern, responsive UI with educational focus
- **📚 Progressive Learning**: 8 modules from basic to advanced topics  
- **💎 Freemium Model**: Free preview modules + premium advanced content
- **🔧 Hermetic Build**: Pure Bazel + bzlmod for reproducible builds
- **⚡ Minimal Dependencies**: CDN-based Tailwind CSS, zero build complexity
- **📱 Mobile First**: Fully responsive design for all devices

## 🏗️ Architecture

### Technology Stack
- **Frontend**: Pure HTML5 + Alpine.js + Tailwind CSS (CDN)
- **Build System**: Bazel + bzlmod (hermetic, zero external deps)
- **Styling**: Tailwind CSS with custom educational theme
- **Interactivity**: Alpine.js for lightweight JavaScript components
- **Deployment**: Static site generation with development server

## 🚀 Build System

### Hermetic Bazel Build
The website uses a completely hermetic Bazel build system with zero external dependencies:

```bash
# Build the complete website
bazelisk build //:site

# Run development server (hermetic)
bazelisk run //:serve

# Create production build
bazelisk build //:build_prod

# Validate HTML structure
bazelisk build //:validate
```

### Key Build Features
- **Zero Dependencies**: No Node.js, npm, or external tools required
- **CDN Integration**: Tailwind CSS loaded via CDN for zero build complexity
- **Hermetic Server**: Python-based dev server generated by Bazel
- **Asset Processing**: Automatic path fixing and optimization
- **Validation**: Built-in HTML structure validation

## 🔧 Development Workflow

### Local Development
```bash
# Navigate to project
cd gazebo_academy_website

# Run development server (hermetic)
bazelisk run //:serve
# Opens http://localhost:8080

# Build for validation
bazelisk build //:validate
cat bazel-bin/validation.txt
```

### Production Deployment
```bash
# Create production tarball
bazelisk build //:build_prod

# Extract for deployment
tar -xzf bazel-bin/gazebo_academy_website.tar.gz

# Deploy static files to your hosting platform
```
